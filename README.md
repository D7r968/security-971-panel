# 🛡️ حماية فورية (971) — موقعها الخاص

موقع مستقل تماماً لبوت **حماية فورية (971)**. الاسم ثابت ولا يمكن تغييره من الواجهة.

- الصفحة الرئيسية: «ضيف البوت الآن» + «شوف المميزات» + «السيطرة»
- تبويب الإعدادات: كل حدود الحماية، التشغيل/الإيقاف، الصلاحيات المحمية
- تبويب السجل: آخر التحذيرات والعقوبات
- تبويب إعادة النشر
